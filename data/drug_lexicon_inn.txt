# International Nonproprietary Names, for the drugs openFDA does not carry.
#
# The openFDA NDC directory is a United States register and lists USAN names,
# so paracetamol is filed as acetaminophen and rifampicin as rifampin. An
# entire vocabulary was missing from a benchmark run on African clinical
# speech: chloroquine, quinine, cotrimoxazole, proguanil, sulfadoxine,
# amodiaquine, dihydroartemisinin, piperaquine, ethambutol.
#
# Source: WHO Model List of Essential Medicines, compiled from the medicine
# names in https://en.wikipedia.org/wiki/WHO_Model_List_of_Essential_Medicines
# (CC BY-SA 4.0), which tabulates the 19th to 24th lists. The underlying WHO
# publication, "The selection and use of essential medicines, 2025: WHO Model
# List of Essential Medicines, 24th list" (hdl:10665/382243), is licensed
# CC BY-NC-SA 3.0 IGO. The names themselves are International Nonproprietary
# Names published by the WHO INN Programme.
#
# Disease names, antiseptics and solvents from the source tables were removed
# by hand, along with entries that name a lab value in dictation rather than a
# prescription: urea, iodine, glycerol, tuberculin.
#
# Every entry has to be lowercase letters only, length 4 or more, and one word.
# entities.find_drug_mentions tokenizes on [\w/.]+ and compares whole tokens,
# so a hyphen or a space makes an entry unmatchable forever. That is why this
# file says cotrimoxazole and not co-trimoxazole. tests/test_lexicon.py pins it.
#
# These are generic provenance: a drug by construction, never dictionary
# filtered. See the asymmetry described in src/lexicon.py.
